## Log

- 2026-07-23: conv_properties.rs only exercises the completeness direction on pairs that are equal (reflexivity) or reduction-related (t ~ whnf t): a conversion checker that answers yes too eagerly would pass every property and only trip the hand-picked golden negatives in tests/conv.rs. Two follow-ups over the wt.rs generator: (1) positive pairs: perturb a well-typed t into a distinct convertible t' - beta-expand a random subterm (wrap in app(lam(x.x); ...) or letbox/box round-trips), eta-expand at Pi/CtxPi/TyPi type, decode-swap El-encodings (El 0 Nat-code vs Nat) - and assert conv holds both ways; with two perturbations of the same t this also tests PER transitivity, and perturbing recursor *branches* finally drives rec_ca's pairwise C_A comparison with differing sides (today that path only ever sees identical branches). (2) negative pairs: small type-preserving-but-value-changing mutations (Zero vs Succ Zero, swapped branches, bumped level annotation where it is not forced) must yield NotConvertible - guards against over-permissiveness. Generator enhancement while there: let gen_const_rec sometimes pick a Gamma-variable of matching CodeTy/CodeTm type as scrutinee so neutral recursors are compared, not just reduced. (Note: neutral UApp heads are unreachable by design - omega-level context entries and global bindings are ill-formed, so no var can have UPi type; not a gap.)
- 2026-07-23: Implemented in tests/conv_pair_properties.rs (7 property tests, 300 seeds each). Positives via common/wt.rs perturb_conv: root-level beta-redex wrap, elim_Nat-on-numeral with constant motive, letbox over fresh code, and eta-expansion at Pi/UPi/CtxPi/TyPi (root-only by design - box bodies compare syntactically, so perturbing under a box breaks convertibility). Both orientations checked, plus two independent perturbations against each other (PER transitivity). El decode-swap done type-side: El^l e vs a hand-decoded twin of the encoding. Negatives assert Err(NotConvertible) exactly (OutOfFuel must not pass): t vs su t at Nat, shape-mutated encodings at Ty l, and box intensionality - box t vs box (su t) AND box t vs box (beta-redex of t). rec_ca with differing sides: gen_nat_rec builds neutral recursors (Var scrutinee, constant Nat motives, branch i = numeral i); a beta-wrapped branch stays convertible, a bumped or swapped branch is NotConvertible. Generator enhancement landed too: gen_const_rec picks a Gamma-variable of matching CodeTy/CodeTm type as scrutinee (1/3 gate via find_code_var); probe showed ~0.8% of general gen_wt_term outputs contain a neutral recursor - opportunistic coverage, the dedicated test is the real driver.
