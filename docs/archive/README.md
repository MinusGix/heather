# Archive

Docs whose subject is gone (the code was deleted, or a later design replaced
them) but whose sections live code still cites, usually for the reasoning
behind a constant or a lemma. They are kept so those citations resolve; they
describe the past, not the tree. Each one's first lines say what replaced it.

A doc whose subject is gone and that nothing live cites is deleted instead;
mentions of it read `docs/<name>.md@<rev>`, and `git show <rev>:docs/<name>.md`
prints it.
